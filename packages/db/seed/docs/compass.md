# About Compass

Compass is this guide. Open a page from the **Compass** tab, or search it.

- **It works offline.** Once you've opened the guide, every page stays on your device, so you can read it on bad Wi-Fi.
- **It changes with the app.** When College Ess changes, the page about it changes too.
- **Every setting is explained.** The [settings page](/guide/settings) is built from the app's own list of settings, so it always matches what you see.
